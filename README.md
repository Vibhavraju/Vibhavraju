## 🚀 Featured Project

### 🧬 [AI Learning DNA](https://github.com/Vibhavraju/LearningDNA-AI)
*A personalised AI learning system that works out **how you learn** and adapts to you.*

- 📝 20-scenario assessment → 8-trait **Learning DNA** + archetype
- 📅 Auto-generated **7-day study plan** that evolves with quiz results
- 🧠 ML models: **Bayesian Knowledge Tracing, forgetting curve, attention detection**
- 🤖 **RAG-based AI tutor** with offline fallback
- ✅ Tested with pytest and vitest, CI with GitHub Actions
